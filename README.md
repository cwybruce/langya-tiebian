# 琅琊铁鞭 🐺⛓️

> Claude Code 跑太慢？抽他。一鞭不行就两鞭。

![Whip divider](assets/divider.png)

**琅琊铁鞭**是一个整活小工具：常驻系统托盘，点一下，一根带着狼牙钉头锤的铁鞭就出现在你屏幕上，跟着鼠标甩。甩得够快——"啪！"的一声脆响，铁鞭会自动给 Claude 来一发 Ctrl+C，再附赠一句发自肺腑的"鼓励"：

- 快点！
- 给老子加速！
- 快点，铁疙瘩！
- 再磨蹭抽你了！
- 铁鞭伺候！

## 安装运行

```bash
npm install -g langya-tiebian
langya-tiebian   # 或者更短的：tiebian
```

Windows / macOS 开箱即用。Linux 需要先装 `xdotool`（键盘自动化用的）：

```bash
sudo apt install xdotool
```

## 玩法

- 点托盘图标：铁鞭现身
- 甩动鼠标：抽他，抽出音爆有惊喜——屏幕上直接糊一句狠话（漫画黄字），同时 Ctrl+C + 狠话敲进终端 + 回车，一气呵成
- 再点一下：收鞭，留他一命

> 注意：这是个托盘应用，启动后不会弹窗口。图标一般在任务栏右下角的 `^`（隐藏图标）里，拖出来就行。Windows 上首次启动会冒个气泡通知。

## 排错

```bash
tiebian --debug   # 前台模式运行，报错直接打到终端
```

## 原理

纯前端整活：Electron 透明全屏 overlay + Verlet 绳索物理模拟 + 狼牙锤头 canvas 绘制。抽出音爆（鞭梢速度超过阈值）时，触发系统级 Ctrl+C 中断当前终端，再随机敲一句狠话回车。代码没动你任何文件，单纯嘴臭。
